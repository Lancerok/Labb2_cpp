## Задача 4

### Текст задачи

Дан набор целых чисел с четным количеством элементов. Заполнить дек D исходными числами, вывести первую половину элементов дека D в обратном порядке, а затем — вторую половину (также в обратном порядке).

### Алгоритм решения

1. Считать количество элементов (должно быть четным).

# Задание 2. Вставка элементов

## Задача 5

### Текст задачи

Даны дек D и список L. Каждый исходный контейнер содержит не менее 5 элементов. Вставить перед пятым с конца элементом списка последние 5 элементов дека в обратном порядке. Использовать один вызов функции-члена insert.

### Алгоритм решения

1. Считать элементы дека D и списка L (проверка на ≥5 элементов).
2. Найти итератор pos в списке L, указывающий на пятый с конца элемент (advance(pos, -5)).
3. Найти итератор d_pos в деке D, указывающий на пятый с конца элемент (advance(d_pos, -5)).
4. Вызвать L.insert(pos, reverse_iterator(D.end()), reverse_iterator(d_pos)) — это вставит последние 5 элементов дека в обратном порядке одним вызовом.
5. Вывести результат.

### Тестирование

| Входные данные (D, L) | Ожидаемый результат |
|------------------------|---------------------|
| D=[1,2,3,4,5,6,7], L=[10,20,30,40,50,60,70] | L=[10, 7, 6, 5, 4, 3, 20, 30, 40, 50, 60, 70] |

# Задание 5. Алгоритмы поиска

## Задача 4

### Текст задачи

Дан список L. Удалить все элементы списка, расположенные между первым и вторым отрицательным элементом (не включая сами отрицательные элементы). Если список не содержит отрицательных элементов, то не изменять его, если отрицательный элемент всего один, то удалить все элементы, следующие за этим отрицательным элементом. Использовать два вызова алгоритма find_if и один вызов функции-члена erase.

### Алгоритм решения

   - Если второй найден: удалить диапазон (next(it1), it2).
   - Если второго нет: удалить диапазон (next(it1), L.end()).

# Задание 9. Множества

## Задача 1

### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1,..., VN. Известно, что размер вектора V0 не превосходит размера любого из векторов V1,..., VN. Найти количество векторов VI, I = 1,..., N, в которых содержатся все элементы вектора V0 (без учета их повторений). Использовать алгоритм includes, применяя его в цикле к двум множествам, одно из которых создано на основе вектора V0, а другое на очередной итерации содержит элементы очередного из векторов VI, I = 1,..., N.

### Алгоритм решения

   - Создать set<int> set_vi из элементов Vi.
   - Проверить includes(set_v0.begin(), set_v0.end(), set_vi.begin(), set_vi.end()).
   - Если true, увеличить счетчик.
4. Вывести счетчик.

# Задание 10. Отображения

## Задача 1

### Текст задачи

Дан вектор V. Определить количество повторений каждого числа в векторе V и вывести все различные элементы вектора V вместе с количеством их повторений (в порядке возрастания значений элементов); количество повторений выводить сразу после значения соответствующего элемента. Использовать вспомогательное отображение M (класс map), ключами которого являются различные элементы вектора V, а значениями — количество повторений этих элементов. При заполнении отображения M не использовать условные конструкции (достаточно операций индексирования [] и инкремента). Элементы вектора V (при заполнении отображения M) и элементы отображения M (при выводе полученных результатов) перебирать в цикле с параметром-итератором соответствующего контейнера.

### Алгоритм решения

1. Считать элементы вектора V.
2. Создать map<int, int> M.
3. Для каждого элемента x в V выполнить M[x]++ — операция [] автоматически создает ключ со значением 0 при первом обращении, поэтому условные конструкции не нужны.
4. Вывести содержимое M через итератор: для каждой пары (key, value) вывести key и value.
5. Поскольку map хранит ключи в отсортированном порядке, вывод автоматически будет в порядке возрастания.

### Тестирование

| Входные данные | Ожидаемый результат |
|----------------|---------------------|
| [3, 1, 2, 3, 1, 3, 2] | 1 2, 2 2, 3 3 |
| [5, 5, 5, 5] | 5 4 |
